# Architecture Decisions / Decisiones de arquitectura

- **EN:** Store concise records of important technical decisions that need lasting context. Do not create a record for every implementation detail.
- **ES:** Guarda registros breves de decisiones técnicas importantes cuyo contexto deba conservarse. No crees un registro para cada detalle de implementación.

Each decision record must be bilingual and use this format / Cada registro debe ser bilingüe y seguir este formato:

- **Status / Estado:** proposed / propuesta; accepted / aceptada; superseded / sustituida; rejected / rechazada
- **Context and problem / Contexto y problema:**
- **Decision and rationale / Decisión y justificación:**
- **Alternatives considered / Alternativas consideradas:**
- **Consequences and trade-offs / Consecuencias y compromisos:**
